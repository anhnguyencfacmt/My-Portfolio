# Anh Nguyen — Investment Research Portfolio

A responsive React, Vite, TypeScript and Tailwind portfolio site.

## Run locally

```sh
pnpm install
pnpm dev
```

## Build and preview

```sh
pnpm build
pnpm preview
```

## Content

- Profile, experience and research card content: `src/data/content.ts`
- Page sections and reusable UI: `src/App.tsx` and `src/components/ui.tsx`
- Research report templates: `public/research/`
- CV download: replace `public/Anh-Nguyen-CV.pdf` with the latest CV

Market quotes and line charts on the dashboard are fictional demo placeholders. Research briefs are templates and must be replaced with completed, sourced analysis before publication.
